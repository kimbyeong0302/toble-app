# 새 책 추가 체크리스트

## 콘텐츠 품질 기준 (전 항목 필수 준수)

1. 본문(verses): supabase/reference-data/krv_full_bible.json에서 추출하고, extract_book_verses.js로 표준 절수와 대조 검증. 틀리면 지어내지 말고 알려줘.
2. 노트(notes): 전체 절의 15~20% 밀도로 선별. 신학적·문학적·역사적으로 의미 있는 절 위주. 특정 역본(개역한글)의 정확한 한국어 단어를 직접 인용하지 말고("~로 번역된" 같은 표현 금지), 원어(헬라어/히브리어) 중심으로 서술.
3. 각주(src): "무거운 주장"(저작연대·저자 논쟁, 본문비평 이슈, 법적/역사적 배경, 논쟁적 신학 해석)에만 달아줘. 반드시 실제 웹 검색으로 확인하고, 확인 안 되면 "확인됨" 표시하지 말고 솔직하게 미확인 상태로 두거나 아예 각주를 달지 마. 실제 논문·주석서·성서공회 자료를 우선 인용해. "검증 완료"라고 스스로 평가하지 말고, 실제로 뭘 확인했는지만 서술해.
4. 인물(people): 본문에 등장하는 주요 인물 최대한 포괄적으로 (최소 10명 이상, 책 분량에 비례해서).
5. 배경(context_html): "한눈에 보기 / 원저자 / 저작연대 / (그 책 고유의) 특징적 주제 / 이야기의 흐름" 카드 구조로. 룻기 전용 트랙(학술/본문중심) 토글은 넣지 마.
6. 지도(map_locations): 각 지점마다 lat/lng/name, "등장 절"(예: "4:5–6"), 그리고 search_aliases 배열(본문이 그 지명을 실제로 어떻게 표현하는지, 여러 표현이 있으면 전부)을 반드시 포함. 표시용 이름(name)과 본문 검색용 표현이 다를 수 있다는 걸 감안해서, name만으로 절을 검색하지 말고 search_aliases도 같이 확인해서 채워줘. 이 책 지도에 새로 등장하는 지명 중 index.html의 LOCATION_INFO에 없는 게 있으면 고도/지형/기후/절기/지명뜻을 실제 검색으로 확인해서 채워줘(지어내지 말고).

## 기술 체크리스트

0. map_locations/LOCATION_INFO 스키마 재확인(search_aliases 필드 포함 여부, 절 색인 로직이 이 필드를 실제로 참조하는지)
1. books 테이블에 등록 여부 확인, 없으면 등록
2. verses upsert + 절수 검증
3. notes 해당 책 범위만 교체
4. people 추가
5. book_extras(context_html + map_locations) 추가
6. LOCATION_INFO 신규 지명 추가

## 검증 (읽기 모드 + 학습 모드 둘 다)

1. 본문 정상 표시(첫 장·마지막 장)
2. ✦ 표시 + 노트 내용(각주 있는 것 1개, 없는 것 1개 둘 다 확인)
3. 소제목 정상 표시
4. 배경·인물 탭 정상 표시
5. 지도 탭 마커 클릭 시 상세정보와 등장 절 목록이 함께 뜨는지 — 특히 본문 표현이 지도 이름과 다른 지명(별칭 필요한 곳)에서도 절이 정상적으로 뜨는지 확인
6. 완성도 점검 화면에서 이 책이 전부 초록불
7. 기존 책 하나 회귀 테스트

## 마지막

다 끝나면 각주 단 노트 목록(어느 절에 무슨 출처인지)을 따로 정리해서 보고해줘.
